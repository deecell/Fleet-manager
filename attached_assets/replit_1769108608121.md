# DeCell Monitor - Truck Battery & Solar Monitoring App

## Overview
A React Native/Expo mobile application for truck drivers to monitor their vehicle's real-time battery and solar data. The app connects to DeCell's backend API to display critical battery metrics in a clean, glanceable interface designed for quick viewing.

## Current State
- MVP implementation complete
- Login authentication flow with DeCell API integration
- Real-time dashboard with auto-refresh every 10 seconds
- Pull-to-refresh functionality

## Tech Stack
- **Frontend**: React Native with Expo SDK 54
- **Backend**: Express.js proxy server
- **State Management**: React Context API + TanStack Query
- **Navigation**: React Navigation 7 (Stack Navigator)
- **Styling**: React Native StyleSheet with custom theme

## Key Features
1. **Login Screen**: Email/password authentication with "Remember Me" option
2. **Dashboard**: 
   - State of Charge (SoC) circular gauge with color-coded status
   - V1/V2 Voltage readings
   - Power (kW) with charge/discharge indicators
   - Energy consumption (kWh)
   - Temperature (°F)
   - Last updated timestamp
3. **Auto-refresh**: Data updates every 10 seconds
4. **Pull-to-refresh**: Manual data refresh
5. **Logout**: Available from header menu

## Design System
- **Primary Color**: Electric Blue (#1E88E5)
- **Status Colors**: Green (healthy), Amber (moderate), Red (low/discharging)
- **Typography**: Large, glanceable text for driver safety
- **Cards**: White surface with subtle shadows

## API Endpoints
- `POST /api/auth/login` - Authenticate user and get truck data
- `GET /api/truck/data` - Refresh truck metrics

## Development Notes
- The app uses simulated truck data with realistic variance for demo purposes
- Auth token is stored in AsyncStorage for persistent sessions
- ErrorBoundary wraps the entire app for crash recovery
